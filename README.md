# 온종일 소셜 서플라이 — 디자인 시안

해외 SMM 공급처(팔로워·좋아요·조회수 등) 상품을 **한국어로 정리해 판매**하고, **리셀러 API**로 파트너에게 재공급하는 서비스의 정적 UI 시안입니다. 셀링포인트 = 한국어 지원 + 한국 결제.

## 포함 화면

- **서비스 몰** — 떡상 히어로, 실시간 통계·라이브 티커, 상품 카탈로그(검색·플랫폼/종류 필터·정렬·더보기), 이용방법·후기·FAQ·결제·CTA
- **주문 모달** — 링크 입력 + 수량 슬라이더 + 실시간 가격 계산
- **마이페이지** — 잔액 충전(가상계좌·카카오·네이버·카드, 보너스 계산) / 주문 내역(진행바·상태·재주문)
- **로그인·회원가입** — 이메일 + 소셜(카카오·네이버)
- **파트너·API** — 재판매 세일즈, 리셀러 API, 파트너 혜택
- **관리자 콘솔** — 로고 7번 클릭 → 비밀번호(123456). 공급처 잔액·내부 지표·상품 공개 관리
- 다크·라이트 테마 전환, 데스크톱·모바일 반응형

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 서버·빌드 불필요.
GitHub Pages: **Settings → Pages**에서 브랜치(main)·루트(/) 선택.

## 참고

디자인 시안입니다. 상품·가격·통계·잔액·API 주소·주문/충전 내역은 전부 예시 데이터이며 실제 주문·결제·API 연동은 동작하지 않습니다. 실서비스에는 공급처 API 연동과 주문·결제·관리 백엔드를 별도로 구현해야 합니다.
